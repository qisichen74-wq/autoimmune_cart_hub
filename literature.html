文献与预印本

Europe PMC 发现层 · 口径是「标题/摘要中出现该病名」，不是疗效证据

这一页上没有任何疗效或安全性数字。 库里也没有 —— 本层能确定的只有"标题或摘要里同时出现了某条模态短语与某条病名短语"。 一篇题为「CAR-T 治疗难治性 SLE：一例报告」的文献，它有没有效、n 是多少、随访多久、 有没有 CRS，一个字都不在检索结果里。 所以这里每一个数字的口径都只能是「标题/摘要中出现该病名」， 而不是「该病的疗效证据 N 篇」。

渠道覆盖面：这个板块看得见什么、看不见什么

先看这一节再看数字。本板块目前只有 Europe PMC 一条腿 —— 会议摘要（ACR / AAN / ECTRIMS / EBMT）与中文期刊一篇也看不见， 而自免细胞治疗的首次人体数据通常先在会议上报告。 也就是说盲区恰好偏在最新、也最受关注的那一端。这不是精度问题，是系统性偏倚。

Europe PMC　已建成

PubMed/MEDLINE 全库、PMC 全文库、以及 bioRxiv / medRxiv / Research Square / Preprints.org / Authorea 等预印本（source=PPR）。 检索只落在标题与摘要上（TITLE_ABS），不做全文匹配。

这个渠道看不见什么：

  • 会议摘要几乎完全看不见。 ACR Convergence / AAN / ECTRIMS / EBMT 的摘要 绝大多数不进 Europe PMC，而自免细胞治疗的首次人体数据通常先在会议上报告。 这是本板块最大的盲区，且它偏在最新的那一端 —— 也就是读者最关心的那一端。
  • 中文期刊看不见。 中华神经科杂志、中华风湿病学杂志一类的中文刊不被 Europe PMC 收录（少量有英文摘要的例外）。本站 in_scope 试验的申办方里 中国占很大比重，因此这与交易层"非 SEC 申报人看不见"是同一个偏倚方向。
  • 检索面被下面那份病名短语清单封顶。 清单外的写法一篇都不会命中。 已实测到的缺口逐条列在 europepmc.gaps_zh 里，带篇数。
  • 只检索标题与摘要。一篇正文里报告了某个自免适应症、但标题与摘要里没提的文献 （例如以肿瘤为题的综述里带一节自免应用）不会被命中。 这是刻意的：改成全文匹配会把"参考文献里提到过这个病名"也算成命中， 而本层产出的是按病归属，判据必须窄。
  • 本渠道只判定"这两类短语出现在同一篇文献的标题或摘要里"， 不判定这篇文献报告了什么结果。疗效与安全性数字一律不从这里来。

四组数字，四件不同的事

分母 / 伞形未认领 / 载体分档 / 疾病归属。任何两件被合并理解都会出错， 最常见的一种是把预印本与同行评议加成一个「文献 N 篇」。

检索面：本站到底查了什么

检索式是模态短语 × 病名短语，两侧都限定在标题与摘要里（TITLE_ABS），不做全文匹配 —— 全文匹配会把"参考文献里提到过这个病名"也算成命中，而本层产出的是按病归属，判据必须窄。

模态短语：chimeric antigen receptor、CAR-T、CAR T-cell、chimeric autoantibody receptor
伞形短语：autoimmune、autoimmune disease、autoimmunity

本层每晚整遍重跑全部查询，没有时间窗、没有回填、也没有索引滞后补偿 —— 因为不需要：全量一遍约 4 分钟（速率 2.0 rps）。所以「这篇文献做过归属了吗」在这一层不是一个问题，不存在交易层那种「窗口外的候选长期未归属」的滞后。

实测一遍 429 条查询、约 4 分钟，resultType=lite。

已实测的缺口（是缺口，不是待办）

这些是判断"某病 0 篇"该怎么读时唯一的依据，原样来自 config/literature_sources.yaml。

  • 4 个病在全部写法下都是 0 篇，那是观测结果，不是缺口。 实测（2026-08-23）逐条试过替代写法后仍为 0： 白塞病（试过 Behcet / Behçet / Behcet's disease / Behcet disease）、 化脓性汗腺炎（hidradenitis suppurativa / acne inversa / hidradenitis）、 过敏性鼻炎（allergic rhinitis / hay fever / rhinitis）、 自身免疫性自主神经节病（autoimmune autonomic ganglionopathy / autonomic ganglionopathy / autoimmune dysautonomia）。 也就是说这 4 个 0 可以读成"CAR 文献里确实没有"。
