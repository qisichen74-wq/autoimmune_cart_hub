这个库是什么，不是什么

全量模态扫（不限适应症）捞到的试验里，全部 condition 都是肿瘤的那些， 入库为参照试验，共 2296 项。它们不参与任何自免计数： 到疾病实体的连接数是 0 条，这个 0 是刻意的， 不是还没连 —— 参照试验没有「该病有几项试验」这个口径。

留着它们的理由是三个问题。今天答得上 1 个（共 3 个）：

问题能否回答依据
同一家公司在肿瘤与自免的并行开发路线 答得上 口径是同一家公司，不是同一个产品。 肿瘤参照侧已归并出 573 家公司，见申办方页。
同一靶点在肿瘤的剂量 / 清淋先例 答不上 要靠干预名人工裁定出靶点与 binder，product 表现有 0 行。这是盲区，不是「没有先例」。
CRS / ICANS 安全性先例 答不上 要逐条抽取不良事件，ae_record 表现有 0 行。同样是盲区。 而且自免适应症可接受的毒性阈值与肿瘤不同，即便抽出来了也不能直接搬 —— 这一条与抽没抽到无关，是口径问题。

所以本页是一个入口与清单，不是一份分析。 把它当成「翻一翻就能找到剂量与毒性」来用，会得到一个没有出处的结论。
